# seo-ops-help

Public Help content for SEO Ops (Markdown + frontmatter).

Source of truth for human-facing Help. Prompt Guidance is **not** stored here.

## Layout

- `VERSION` — cache invalidation key for clients
- `docs/{group}/*.md` — Help topics
- `images/` — lightweight screenshots

## Topic frontmatter

`key`, `title`, `summary`, `group`, `sort_order`, `status`, `keywords`, `related`, `video`, `updated_at`
