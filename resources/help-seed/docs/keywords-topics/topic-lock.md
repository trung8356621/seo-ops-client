# Khóa Topic

Khi Topic bị khóa, hệ thống không tự gom / tách keyword ra khỏi topic đó trong các vòng cluster tự động.

Dùng khi cấu trúc topic đã ổn định và bạn không muốn AI/auto-reconcile làm xáo trộn.
