# Task Workflows

Task Workflows điều phối các bước vận hành trong SEO Ops.

## Dùng để làm gì?

- Chọn Task chạy khi tạo/đăng bài viết
- Chọn Task chạy khi đăng bình luận ảo lên WordPress
- Mở Workflow Builder để kiểm tra role/capability còn thiếu

## Lưu ý

Prompt Block bên trong Task tham chiếu `prompt_id` trực tiếp.

Health warning dưới field là trạng thái runtime — không phải tài liệu hướng dẫn.
