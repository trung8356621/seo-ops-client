# Prompt Design

Best practices khi thiết kế Prompt cho ảnh typography / infographic.

## Recommended

- Keep sections short.
- Prefer icons over paragraphs.
- Maximum 2 visible text lines per card.
- Large typography.
- High whitespace.

## Avoid

- Long paragraphs.
- Too many numbers in one card.

## Where to configure

Settings → Workflows — Prompt Hooks / Prompt bindings.
