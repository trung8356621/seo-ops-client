# Typography Validation

Kiểm tra chữ sau khi render ảnh typography/infographic.

## Các thiết lập chính

- Bật/tắt validation
- Mức kiểm tra (Rendering Preference)
- Model vision dùng để validate
- Số candidate tối đa và ngưỡng pass
- Cho phép fallback sang General Image khi thiếu typography model

## Khi nào thay đổi?

- Khi ảnh typography thường fail validation quá nghiêm
- Khi muốn siết chất lượng chữ trên ảnh
- Khi thiếu model typography và cần fallback an toàn
