# AI Model Updates

Google updates models frequently.

## If image quality suddenly changes

1. Sync models.
2. Check Routing.
3. Benchmark another Image model.
4. Do not immediately modify prompts.

## Where to configure

Settings → AI Center — models inventory and routing.
