# Workflow Media Extract

Khi Editor Media dùng nguồn Workflow, SEO Ops lấy Prompt media từ Task đã chọn.

## Phase hiện tại

Phase 1: lấy Prompt hình ảnh/video cuối trong workflow.

Chưa chạy toàn bộ graph execution tại bước cấu hình này.

## Khi nào thay đổi?

- Khi muốn media editor đi theo một Task cố định
- Khi Prompt trực tiếp không còn phù hợp và bạn muốn orchestration qua Workflow
