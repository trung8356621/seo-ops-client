# Team Chat Uploads

Giới hạn loại tệp và dung lượng khi thành viên gửi file trong phòng chat nhóm.

## Allowed extensions

Mỗi phần mở rộng một dòng hoặc cách nhau bằng dấu phẩy.

Ví dụ: `jpg`, `png`, `pdf`, `zip`

## Max file size

Áp dụng cho upload và dán ảnh Ctrl+V trong chat nhóm.
