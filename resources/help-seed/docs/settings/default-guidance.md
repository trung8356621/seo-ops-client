# Default Guidance

Default Guidance là hướng dẫn mặc định mà SEO Ops dùng để quy định cách AI nên xử lý một tác vụ.

## Nó khác Prompt như thế nào?

Prompt là nội dung hoặc template được chọn cho tác vụ.

Default Guidance mô tả các yêu cầu nền như:

- dạng output mong muốn
- dữ liệu được truyền vào
- giới hạn hoặc quy tắc cần tuân theo

## Khi nào cần xem?

- Khi muốn hiểu một Hook yêu cầu AI trả về dạng gì
- Khi kiểm tra vì sao Prompt cần một số biến hoặc dữ liệu nhất định
- Khi tạo hoặc chỉnh Prompt cho Hook đó

## Lưu ý

Default Guidance là instruction dành cho AI/model.

Nội dung Guidance thật vẫn được quản lý trong Workflow (View default guidance).

Help này chỉ giải thích cho người dùng hiểu chức năng đó.
