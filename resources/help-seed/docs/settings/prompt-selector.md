# Chọn Prompt

Danh sách Prompt cho phép bạn chọn Prompt được dùng cho tác vụ hiện tại.

## Khi thay đổi Prompt

Thay đổi này ảnh hưởng tới những lần chạy tiếp theo của chức năng đó.

Hãy chọn Prompt có đúng mục đích với Hook đang cấu hình.

## Lưu ý

Không nên chọn Prompt chỉ dựa vào tên.

Nếu cần, mở Prompt Management để xem nội dung và mục đích của Prompt trước khi gắn.
