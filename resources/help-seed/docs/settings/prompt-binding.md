# Prompt Binding

Prompt Binding xác định Prompt nào được sử dụng cho một chức năng cụ thể.

## Cách dùng

Chọn Prompt trong danh sách của Hook tương ứng.

Chỉ các Prompt phù hợp với Hook hiện tại mới xuất hiện trong danh sách.

## Lưu ý

Prompt tồn tại nhưng chưa được gắn vào Hook phù hợp sẽ không tự động được sử dụng khi hệ thống chạy.

Hook = loại Prompt. Settings binding = nơi sở hữu cấu hình.
