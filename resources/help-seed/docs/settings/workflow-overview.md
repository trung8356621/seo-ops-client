# Workflow Settings

Workflow Settings xác định cách các chức năng trong SEO Ops kết nối với Prompt và các thiết lập được dùng khi chạy.

## Dùng để làm gì?

- Xem chức năng nào đang sử dụng Prompt hoặc Task nào
- Chọn Prompt/Task phù hợp cho từng loại tác vụ
- Kiểm tra cấu hình mặc định trước khi chạy
- Tránh trường hợp Prompt tồn tại nhưng chưa được gắn vào chức năng

## Lưu ý

Workflow Settings dùng để cấu hình cách hệ thống vận hành.

Nó không phải nơi chỉnh trực tiếp nội dung bài viết.
