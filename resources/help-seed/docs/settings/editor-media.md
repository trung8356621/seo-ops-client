# Editor Media Sources

Phần này chọn nguồn tạo media trong Article Editor: Prompt trực tiếp hoặc Task Workflow.

## Dùng để làm gì?

- Typography / Infographic khi bấm «Tạo ảnh»
- Video generation
- Chọn Prompt hoặc Workflow tương ứng

## Lưu ý

Cấu hình model ưu tiên nằm ở Settings → AI Advanced.

Nếu chọn Workflow, hệ thống lấy Prompt media theo cấu hình extract hiện tại của workflow đó.
