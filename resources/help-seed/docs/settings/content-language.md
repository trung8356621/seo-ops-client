# Default Content Language

Dùng làm mặc định cho site chưa chọn ngôn ngữ nội dung riêng.

## Lưu ý

Đây không phải ngôn ngữ giao diện ứng dụng (EN/VI).

Site có thể ghi đè bằng cấu hình domain/site riêng nếu có.
