# Product Gallery Source

Nguồn tạo Gallery sản phẩm quyết định hệ thống dùng Prompt Hook hay Task Workflow.

## Cách dùng

- **Prompt**: dùng Prompt đã gắn tại Hook Product gallery
- **Workflow**: dùng Task Workflow được chọn riêng

## Lưu ý

Khi chế độ Prompt được chọn, phải có Prompt trong Hook card Product gallery trước khi lưu.

Trạng thái «Prompt in use» / «No Prompt selected» là runtime status — không phải tài liệu.
