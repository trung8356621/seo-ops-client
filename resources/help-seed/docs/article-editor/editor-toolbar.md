# Editor Toolbar

Định dạng chữ, list, link, bảng….

## Khi nào sử dụng?

- Khi cần in đậm/nghiêng
- Khi chèn list hoặc link
- Khi thêm bảng/quote

## Cách dùng

- Chọn đoạn cần sửa
- Dùng nút trên toolbar
- Kiểm tra kết quả trong editor

## Lưu ý

Toolbar chỉ hỗ trợ định dạng nội dung — không gồm SEO/AI tools.
