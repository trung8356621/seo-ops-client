# HTML Mode

Xem/sửa HTML khi cần kiểm soát markup.

## Khi nào sử dụng?

- Khi cần chỉnh HTML thủ công
- Khi debug markup
- Khi chèn snippet HTML có kiểm soát

## Cách dùng

- Mở HTML mode cho đoạn tương ứng
- Chỉnh cẩn thận
- Quay lại chế độ thường để kiểm tra

## Lưu ý

Sửa HTML sai có thể làm hỏng bố cục — chỉ dùng khi cần.
