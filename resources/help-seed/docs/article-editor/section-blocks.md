# Section Blocks

Làm việc theo từng khối nội dung.

## Khi nào sử dụng?

- Khi bài có nhiều section
- Khi muốn sửa một đoạn cụ thể
- Khi cấu trúc bài theo block

## Cách dùng

- Chọn section/block cần sửa
- Chỉnh nội dung trong block
- Giữ heading/cấu trúc rõ ràng

## Lưu ý

Mỗi Help Topic vẫn là một file Markdown; section ở đây là cấu trúc bên trong bài viết.
