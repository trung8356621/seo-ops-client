# Typography

Image AI currently draws text instead of rendering fonts.

## Expect

- 0–2 spelling mistakes
- Minor OCR errors

## Suitable for

- SEO articles
- Blog infographics

## Not recommended for

- Print
- Marketing materials requiring 100% accurate text

## Related settings

Validation toggles and thresholds live under Settings → AI Advanced → Typography validation.
