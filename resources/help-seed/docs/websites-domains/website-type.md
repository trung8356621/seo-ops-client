# Website Type

Chọn loại website để SEO Ops áp dụng đúng mô hình nội dung, topic và gợi ý SEO.

## Các lựa chọn thường dùng

- **News** — bài tin, cập nhật thường xuyên
- **Production** — site sản xuất / catalog sản phẩm
- **E-commerce** — cửa hàng, tập trung sản phẩm và chuyển đổi

Website Type ảnh hưởng cách hệ thống đọc cấu trúc nội dung — không phải nhãn trang trí.
