# Global CTA Contacts

Danh sách liên hệ dùng chung — áp dụng cho mọi domain qua placeholder như `[zalo]`, `[address]`, `[working_hours]`.

## Dùng để làm gì?

- Khai báo một lần các thành phần CTA dùng chung
- Tránh cấu hình lặp lại trên từng domain

## Lưu ý

Cấu hình theo domain vẫn có thể bổ sung contact riêng nếu UI domain hỗ trợ.
